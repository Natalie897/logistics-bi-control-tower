# Демонстрационные данные
CSV-таблицы полностью **синтетические**. Они создаются детерминированно командой `python -m etl.generate_demo`.
В данных специально есть отменённые заказы, опоздания, разные регионы и тарифы доставки.
Это учебный клиентский кейс. «Интервью с заказчиком» в документах — имитация, не реальное интервью.
