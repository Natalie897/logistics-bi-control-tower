# Имитация встречи с заказчиком (учебный сценарий)

**Заказчик (вымышленный):** руководитель логистики маркетплейса `Northstar Commerce`.
**Аналитик:** стажёр BI-консалтинга.
**Участники / ответы ниже вымышлены**, чтобы потренировать процесс интервью и согласования требований.

## Discovery: 8 вопросов и согласованные гипотезы

1. Для кого решение? — Директор по операциям, руководитель логистики, региональные менеджеры.
2. Какую проблему решаем? — Избыточное время на подготовку недельного отчёта и разные определения SLA.
3. Что считается вовремя? — Дата фактической доставки ≤ обещанной клиенту даты.
4. Что делать с отменами? — Исключать из расчёта On Time Rate, отображать отдельной метрикой.
5. Что нужно фильтровать? — Дата покупки, регион, способ доставки.
6. Какова детализация? — Один заказ в таблице фактов; линии товаров агрегируются заранее.
7. Как будет приниматься работа? — Сверка SQL, Excel и Power BI на одинаковом срезе.
8. Какие права доступа? — В PoC только обезличенные/синтетические данные; продакшен RBAC и PII вне объёма.

## Ограничения PoC
Работа выполняется как демонстрационное проектирование, без фактически проведённых интервью, согласования реальным клиентом и промышленного внедрения. Даты, данные, роли и «согласования» учебные.
