# Сценарий интервью для самостоятельной практики

Задайте 10 вопросов воображаемому клиенту: кто пользуется отчётом, периодичность, цели, существующие отчёты, пороги SLA, исключения, справочники, персональные данные, критерии приёмки, правила работы с отменами.
В `CASE_CONTEXT.md` приведён один **учебный** вариант ответов. Для тренировки попробуйте сначала самостоятельно заполнить таблицу из трёх колонок: «Вопрос — Ответ — Требование». Не выдавайте эту работу за реальный клиентский опыт.
