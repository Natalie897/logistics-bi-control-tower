# Критерии приёмки / UAT (все роли вымышленные)

| ID | Пользовательская история | Проверка | Ожидаемый результат |
|---|---|---|---|
| UAT-01 | Как руководитель логистики, хочу видеть % SLA | Сверить Power BI и SQL Q1 | Цифры совпадают после одинаковых фильтров |
| UAT-02 | Как аналитик, хочу выбирать регион | Выбрать Southeast | Все карточки и графики пересчитываются |
| UAT-03 | Как руководитель, хочу не учитывать отмены в SLA | Проверить 1 отменённый заказ | Не влияет на числитель и знаменатель SLA |
| UAT-04 | Как аналитик, хочу месячную динамику | Проверить 2 месяца | Корректно отображаются по календарю |
| UAT-05 | Как пользователь, хочу видеть причины отклонений | Матрица регион × тип доставки | Есть сравнение задержек между сегментами |
| UAT-06 | Как инженер данных, хочу контроль загрузки | Отрицательная стоимость в CSV | ETL завершает работу с ошибкой |
| UAT-07 | Как инженер данных, хочу отсутствие размножения заказов | Сверить COUNT(DISTINCT order_id) | Равен числу строк фактов |
| UAT-08 | Как заказчик, хочу справедливую интерпретацию | Проверить описания финансовых показателей | Отсутствуют утверждения о фактической прибыли |

## Известные ограничения
- Тренд по месяцу покупки, не по месяцу доставки.
- По умолчанию источник полностью синтетический.
- Для Olist «SLA» технически сравнение с обещанной датой доставки, а не юридически согласованным SLA перевозчика.
- Если реальный датасет не содержит тип доставки, `not_provided` не позволяет анализировать логистические услуги.
